# Tarea 2 - Programas e invariante de ciclo

Esta carpeta contiene la segunda tarea de Análisis y Diseño de Algoritmos.

## Contenido

- T2.pdf: enunciado original de la tarea.
- algoritmos/: implementación en Rust.
- reporte/: fuente LaTeX, figuras, capturas de ejecución y evidencia de la
  prueba de escritorio.
- Archivos MP4: videos proporcionados para el análisis de invariante de ciclo
  y correctez de algoritmos iterativos.

## Actividades resueltas

1. INSERTION-SORT ascendente.
2. INSERTION-SORT descendente.
3. Suma de dos números binarios almacenados en arreglos.
4. Prueba de escritorio de INSERTION-SORT.
5. Síntesis de invariante de ciclo y correctez de algoritmos iterativos.

## Ejecución del programa

Desde la carpeta algoritmos/:

    cargo run

## Compilación del reporte

Desde la carpeta reporte/:

    xelatex reporte_tarea_2.tex

Se utiliza XeLaTeX porque el reporte emplea las fuentes Times New Roman y Menlo.
